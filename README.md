# GREEN-API MAX Chat

React-приложение для отправки и получения текстовых сообщений через GREEN-API MAX.

## Возможности

- Отправка текстовых сообщений в MAX
- Получение входящих сообщений через receiveNotification
- Проверка состояния инстанса
- Интерфейс в стиле MAX

## Технологии

- React
- TypeScript
- Vite
- GREEN-API

## Запуск

Установка:

npm install

Запуск:

npm run dev
